# Geo assets

- `countries-110m.json`, `countries-50m.json` — TopoJSON from Natural Earth via
  the world-atlas project. Used for the globe base, country borders, highlights
  and shape silhouettes.
- `earth-texture.jpg` — Natural Earth II with Shaded Relief and Water
  (`NE2_50M_SR_W`), downsampled from 10800x5400 to 1024x512. Sampled per pixel
  at render time to colour the land with real land cover instead of a guess.

All Natural Earth data is public domain. https://www.naturalearthdata.com/about/terms-of-use/
